# RestOS Website

Marketing website for RestOS — The Operating System For Restaurants.

Built with Next.js 14, Tailwind CSS, and Framer Motion.

## Setup

```bash
npm install
npm run dev
```

## Before Launch

Update these values in `src/lib/constants.ts`:
- `WHATSAPP_NUMBER` — your WhatsApp Business number (format: 919XXXXXXXXX)
- `YOUTUBE_VIDEO_ID` — YouTube video ID from your product demo URL
- `FOUNDING_SPOTS_TAKEN` — increment manually as restaurants onboard

## Deploy

Push to GitHub, then import to Vercel. No environment variables needed.
